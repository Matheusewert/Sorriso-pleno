# Sorriso Pleno

Site institucional da Clínica Odontológica fictícia **Sorriso Pleno**, com 10 páginas, desenvolvido em equipe na disciplina de Desenvolvimento Front-End para Web (UNICID, curso de Análise e Desenvolvimento de Sistemas).

## Objetivo
Praticar HTML5 e CSS3 construindo um site com várias páginas conectadas, navegação clara e padrão visual único, sem usar templates prontos.

## Páginas
- Início
- A Clínica
- Tratamentos
- Especialidades
- Dentistas
- Antes e Depois
- Depoimentos
- Perguntas Frequentes
- Dicas de Saúde Bucal
- Contato

## Funcionalidades
- Menu de navegação entre as 10 páginas.
- Layout e identidade visual padronizados em todo o site.
- Conteúdo informativo sobre serviços, equipe e cuidados com a saúde bucal.

## Tecnologias
- HTML5
- CSS3
- Visual Studio Code

## Como visualizar
1. Baixe o repositório (**Code > Download ZIP**) e extraia os arquivos.
2. Abra o arquivo `index.html` no navegador.
